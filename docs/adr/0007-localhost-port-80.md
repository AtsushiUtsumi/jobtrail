# 0007. 80 番ポートと localhost 限定

**状況**: 認証を持たず、個人情報を扱う。URL は短いほうが設定しやすい。

**決定**: 外部に出すのは frontend の 80 番のみとし、`127.0.0.1` にバインドする。`HTTP_PORT` で変更できる。
`Host` を `localhost` / `127.0.0.1` に限定し、`/mcp` では `Origin` も検証する。

**結果**: UI・API・MCP が同一オリジンになり CORS が不要になる。ブラウザ経由の DNS rebinding を防げる。
80 番が使用中の環境では `.env` の変更が必要になる。
